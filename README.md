# openparts-data

Canonical electronic part data for [OpenParts](https://github.com/openparts-org/openparts): parts, devices, packages and the sources they cite. Most of it is AI-extracted and unreviewed; see [CONTRIBUTING.md](CONTRIBUTING.md) to check it against the datasheets, fix it or add parts.

It records facts (values, units, conditions) read from manufacturers' datasheets, with short locators; it contains no datasheet text, figures or tables.
